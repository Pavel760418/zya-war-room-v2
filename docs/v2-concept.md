# Что добавлено в v2

## 1. Drill-down карточка магазина

Карточка магазина стала отдельным управленческим слоем, а не просто фильтром таблицы. Она показывает:
- KPI по дням, неделям и месяцам в одном экране
- причины отклонений
- локальные риски магазина
- сравнение магазина с сетью
- блок приоритетных действий

## 2. Action layer

Action layer — это интерпретатор цифр в управленческие действия. Логика строится на порогах KPI:
- низкая доступность ТЗ → проверить выкладку, поставку, планограмму
- низкая доступность Производства → проверить выпуск, матрицу, сырье, график производства
- низкий вес СП → проверить ассортимент, наличие, списания и операционный выпуск
- рост остатков → проверить перетарку, заказы, оборачиваемость
- рост списаний → разобрать группы потерь и ответственных
- недовыполнение плана → проверить трафик, conversion proxy, availability, промо и локальные причины

## 3. Demo mode

В demo mode backend генерирует сеть из 24 магазинов с вариативными профилями:
- сильные флагманы
- стабильные магазины
- средняя группа
- проблемные магазины
- критические магазины

Это нужно, чтобы увидеть как интерфейс читается в боевом режиме: где взгляд руководителя цепляется за цвет, где таблица перегружена, где карточки и action layer действительно помогают, а где требуют упрощения.
